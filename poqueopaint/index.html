Como surgiu a Idéia

Eu estava no Aseprite, tentando desenhar algo pra um jogo meu, quando lembrei da “estética” do Paint: o traço meio torto, a falta de ferramentas, o visual pixelado. Tudo isso vem da limitação, e é justamente isso que dá charme.

Meu contato com o Paint foi pequeno. Passei por ele dos 6 aos 7 anos, entre jogos web e alguns rabiscos, e só voltei a mexer com esse tipo de coisa lá pelos 13 ou 14, quando dei uma fuçada leve no GameMaker. Eu praticamente sempre usei Linux, mas esse pouco contato com o Windows 10 e com o Paint foi suficiente pra me fazer sentir como se tivesse vivido nele.

Então resolvi fazer algo que remetesse a isso. O diferencial é que cada traço pode ser apagado de uma só vez. Ainda não tem suporte a fundo transparente, que é o que me falta pra usar de verdade nos meus jogos, mas esse é o próximo passo.

O Projeto num Geral

Comecei prototipando rápido em Python + Arcade, mas perdi esse protótipo. Migrei pra Rust por três motivos: eu estava começando na linguagem, achei que seria melhor a longo prazo, e o cross-compile ajuda bastante. As libs são gl 0.14 pra todo o render, glfw 0.55 pra janela e image 0.25 pra exportar.

Usei OpenGL direto, sem egui ou macroquad, porque senti que seriam abstração demais. Se eu quiser adicionar pós-processamento no futuro, ou manter tudo leve, prefiro ter controle sobre o que roda.

Como o Apagador Funciona

Aqui, “só vetores” quer dizer que eu não guardo pixels. Cada traço é um dado: uma lista de pontos, uma largura e uma cor. No fim tudo vira pixel na tela, claro, mas como o traço continua existindo como dado, dá pra apagar ele inteiro.

Pra isso a borracha mede a distância do cursor até cada segmento do traço (point_segment_dist, que projeta o ponto no segmento e limita o resultado ao começo e ao fim dele). Se a menor distância estiver dentro do raio da borracha, o traço inteiro sai da lista.

Um detalhe é que eu percorro os índices em ordem decrescente. Remover um item desloca os seguintes, então apagar de trás pra frente garante que os índices que ainda faltam continuam válidos. Cada remoção também vai pro histórico como HistoryOp::Remove(i, removed), e é isso que permite desfazer. O hovered_stroke usa a mesma conta pra destacar o traço que vai ser apagado antes do clique.

#[derive(Clone)]
pub struct Stroke {
    pub points: Vec<(f32, f32)>,
    pub width: f32,
    pub color: Rgb,
}

impl Stroke {
    /// Distância mínima de um ponto até o traço (pra hit-test da borracha).
    fn distance_to(&self, p: (f32, f32)) -> f32 {
        if self.points.len() == 1 {
            return dist(self.points[0], p);
        }
        let mut best = f32::MAX;
        for w in self.points.windows(2) {
            let d = point_segment_dist(p, w[0], w[1]);
            if d < best {
                best = d;
            }
        }
        best
    }
}

fn dist(a: (f32, f32), b: (f32, f32)) -> f32 {
    ((a.0 - b.0).powi(2) + (a.1 - b.1).powi(2)).sqrt()
}

fn point_segment_dist(p: (f32, f32), a: (f32, f32), b: (f32, f32)) -> f32 {
    let (px, py) = p;
    let (ax, ay) = a;
    let (bx, by) = b;
    let dx = bx - ax;
    let dy = by - ay;
    let len_sq = dx * dx + dy * dy;
    if len_sq < 1e-6 {
        return dist(p, a);
    }
    let t = (((px - ax) * dx + (py - ay) * dy) / len_sq).clamp(0.0, 1.0);
    let proj = (ax + t * dx, ay + t * dy);
    dist(p, proj)
}

fn erase_at(&mut self, p: (f32, f32)) {
    let radius = self.erase_radius();
    // índices em ordem decrescente: remover um não desloca os próximos da lista
    let to_remove: Vec<usize> = (0..self.strokes.len())
        .rev()
        .filter(|&i| self.strokes[i].distance_to(p) <= radius)
        .collect();
    for i in to_remove {
        let removed = self.strokes.remove(i);
        self.drag_ops.push(HistoryOp::Remove(i, removed));
    }
}

/// Traço (se houver) sob o cursor agora — destaque de "vai apagar isso".
pub fn hovered_stroke(&self, p: (f32, f32)) -> Option<usize> {
    if self.tool != Tool::Eraser {
        return None;
    }
    let radius = self.erase_radius();
    (0..self.strokes.len())
        .rev()
        .find(|&i| self.strokes[i].distance_to(p) <= radius)
}
