Como surgiu a Idéia

Eu tava no Aseprite tentando desenhar algo pra um jogo meu aleatório e então eu lembrei da “estética” que o Paint tem, que vem justamente da limitação.

Então eu comecei a trabalhar em algo que remetesse ao Paint, só pela nostalgia do Win 10. Eu sempre usei Linux, mas o contato que eu tive com o Windows e com o Paint me fez sentir como se eu tivesse vivido nele. Então eu decidi fazer esse projeto: apesar de ainda não ter suporte ao fundo transparente pra usar realmente nos meus jogos, eu fiz cada traço ser apagável de uma só vez, sem rasterização, só vetores.

O Projeto num Geral

Eu comecei prototipando rapidamente em Python + Arcade — infelizmente eu perdi esse protótipo kkkkkkkk. E então eu migrei pra Rust, com essas libs: gl 0.14 pra todo o render, glfw 0.55 pra janela e image 0.25 pra exportar.

O Código de Verdade

Aqui vai como eu fiz os vetores serem apagáveis individualmente:

#[derive(Clone)]
pub struct Stroke {
    pub points: Vec<(f32, f32)>,
    pub width: f32,
    pub color: Rgb,
}

impl Stroke {
    /// Distância mínima de um ponto até o traço (pra hit-test da borracha).
    fn distance_to(&self, p: (f32, f32)) -> f32 {
        if self.points.len() == 1 {
            return dist(self.points[0], p);
        }
        let mut best = f32::MAX;
        for w in self.points.windows(2) {
            let d = point_segment_dist(p, w[0], w[1]);
            if d < best {
                best = d;
            }
        }
        best
    }
}

fn dist(a: (f32, f32), b: (f32, f32)) -> f32 {
    ((a.0 - b.0).powi(2) + (a.1 - b.1).powi(2)).sqrt()
}

fn point_segment_dist(p: (f32, f32), a: (f32, f32), b: (f32, f32)) -> f32 {
    let (px, py) = p;
    let (ax, ay) = a;
    let (bx, by) = b;
    let dx = bx - ax;
    let dy = by - ay;
    let len_sq = dx * dx + dy * dy;
    if len_sq < 1e-6 {
        return dist(p, a);
    }
    let t = (((px - ax) * dx + (py - ay) * dy) / len_sq).clamp(0.0, 1.0);
    let proj = (ax + t * dx, ay + t * dy);
    dist(p, proj)
}

fn erase_at(&mut self, p: (f32, f32)) {
    let radius = self.erase_radius();
    // índices em ordem decrescente: remover um não desloca os próximos da lista
    let to_remove: Vec<usize> = (0..self.strokes.len())
        .rev()
        .filter(|&i| self.strokes[i].distance_to(p) <= radius)
        .collect();
    for i in to_remove {
        let removed = self.strokes.remove(i);
        self.drag_ops.push(HistoryOp::Remove(i, removed));
    }
}

/// Traço (se houver) sob o cursor agora — destaque de "vai apagar isso".
pub fn hovered_stroke(&self, p: (f32, f32)) -> Option<usize> {
    if self.tool != Tool::Eraser {
        return None;
    }
    let radius = self.erase_radius();
    (0..self.strokes.len())
        .rev()
        .find(|&i| self.strokes[i].distance_to(p) <= radius)
}
